# PriceRadar-NG 

> A Nigerian market price tracking and reporting platform designed to help users explore, compare, and report the prices of everyday goods.

## 📌 About the Project

**PriceRadar-NG** is a frontend web application focused on making market price information easier to view and understand.

The project provides a dashboard-style interface where users can navigate through different sections of the platform, explore market prices, compare items, submit price reports, and access user and administrative sections.

The project is currently being developed as a frontend application, with room for future backend integration and additional functionality.

## ✨ Features

* 🏪 **Market** — Browse market and product price information.
* 📊 **Compare** — Compare prices across different items or markets.
* 📝 **Report a Price** — Submit market price information to help contribute to the platform.
* 👤 **Profile** — Dedicated profile section for users.
* 🛡️ **Admin** — Administrative section for managing the platform.
* 🔎 **Search Interface** — Search UI for finding items and markets.
* 📱 **Responsive Design** — Layouts designed to adapt to different screen sizes.
* 🎨 **Modern UI** — Clean interface with a green-focused visual design.

## 🎯 Project Goal

The goal of PriceRadar NG is to create a platform that can make Nigerian market price information more accessible.

The project is designed around three important ideas:

**Discover → Compare → Report**

Users should be able to discover market prices, compare prices between items or locations, and contribute new price information through reports.
